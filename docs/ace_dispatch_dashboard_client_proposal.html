Smart Dispatch Dashboard Proposal

A simple, modern control panel to manage rides from WhatsApp groups and OTS Supplier Portal in one place, reduce manual work, improve driver assignment, and find return ride opportunities.

1. What We Are Building

We will build one central dashboard for the dispatch team. Instead of checking multiple WhatsApp groups, Google Sheets, and OTS portal outputs separately, the operator will see everything in one clean system.

2. Main Benefits

One Control Room All rides from WhatsApp and OTS will appear in one dashboard.
Less Manual Work The system will extract ride details, sort jobs, suggest drivers, and prepare assignments.
Better Driver Usage The dashboard will help find return rides and reduce empty driving.
Cleaner Operations Old completed or invalid rides will be archived or deleted automatically.

3. Ride Sources

Source What Happens
WhatsApp Groups Ride messages are read, cleaned, and converted into proper ride records.
OTS Supplier Portal Available jobs are collected from the supplier portal and added into the same dispatch flow.

4. Dashboard Sections

Section Purpose
Dashboard Quick overview of today jobs, pending approvals, assigned rides, revenue, and calendar issues.
Live Rides All incoming rides from WhatsApp and OTS with filters by source, date, status, vehicle, and fare.
Needs Review Rides with missing or unclear details. Operator can correct them before dispatch.
Final Bid Qualified rides ready for driver recommendation and dispatch approval.
Driver Recommendations The system suggests the best driver and vehicle with a score and reason.
Linked Rides Return ride opportunities where one driver can complete multiple compatible jobs.
Drivers & Vehicles Live status, availability, current location, and future bookings.
Calendar Shows whether calendar events were created successfully or failed with a reason.
Reports Completed jobs, revenue, driver usage, linked ride savings, and operational performance.

5. Operator Workflow

Step Operator View
1. Ride Arrives New WhatsApp or OTS ride appears in Live Rides.
2. System Checks Ride Clean rides move forward. Unclear rides go to Needs Review.
3. Recommendation Created Dashboard shows recommended driver, vehicle, score, and reason.
4. Operator Approves Operator clicks approve. The driver and vehicle are assigned automatically.
5. Schedule Updates Driver and vehicle timelines update to prevent double booking.
6. Calendar Updates Calendar event is created and status is shown on dashboard.

6. Return Ride / Linked Ride Intelligence

The system will try to match rides together so drivers can complete more jobs with less empty driving.

Example: If one ride drops in Chelsea and another ride starts from Chelsea later, the dashboard will show this as a linked ride opportunity.
  • Checks previous drop-off and next pickup location.
  • Checks time gap between rides.
  • Checks driver and vehicle availability.
  • Checks vehicle type compatibility.
  • Shows estimated saving or benefit on dashboard.

7. Future Ride Handling

Future rides must not be deleted just because they are far ahead. If a ride is 40 days in the future, it will stay active and searchable.

  • Future rides remain active until the ride date passes.
  • The system will still try to find linked rides around that future date.
  • Completed old rides can be archived later to keep the dashboard clean.

8. Automatic Data Cleanup

Data Type Rule
Future rides Keep active until ride date passes.
Completed rides Keep for 10 days, then archive.
Invalid/trash rides Remove or archive after 3-5 days.
Needs Review old items Archive after 7-10 days if unresolved.
Expired linked opportunities Mark expired automatically.

9. Future Add-On: Auto Bidding

A future add-on can automatically bid on rides when the ride matches company criteria. This should first be launched in a safe approval mode, then later moved to automatic mode when proven reliable.

How Auto Bidding Will Work

  • System finds a new ride from OTS or WhatsApp.
  • System checks fare, distance, pickup area, vehicle type, driver availability, and linked ride opportunity.
  • If the ride matches criteria, the dashboard shows Auto Bid Suggested.
  • Operator can approve the bid manually at first.
  • Later, high-confidence rides can be bid automatically.
  • Every bid decision will be saved in the audit log.

Auto Bidding Modes

Mode Description
Suggest Only System recommends which rides to bid on. Operator approves manually.
Assisted Auto Bid System bids only on high-confidence rides under strict rules.
Full Auto Bid System bids automatically, with complete dashboard visibility and audit history.
